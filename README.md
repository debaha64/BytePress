# BytePress Harness

## Назначение

BytePress Harness — продуктовая обвязка для управляемой работы над Product Unit. Она разделяет продуктовый смысл, решения владельца, планы, свидетельства, процедуры, формы и механические проверки.

```text
Человек управляет, агенты исполняют.
```

Workspace служит средой работы, а Product Unit остаётся самостоятельной продуктовой единицей и не управляет Workspace.

## Быстрый старт

1. Прочитайте [AGENTS.md](AGENTS.md) и [SYSTEM.md](SYSTEM.md).
2. Откройте [первый старт](docs/user/first-start.md) и [описание операционного режима](docs/user/operating-mode.md).
3. Подготовьте вход текущего `SOT_MODE` по [нормативной процедуре](sops/sot.md).
4. Продолжайте работу по текущему состоянию в `plans/` и процедурам из [sops/](sops/README.md).
5. Выполняйте механические проверки только на разрешённой рабочей копии.

Для `sot_github` сначала используйте [инструкцию подготовки репозитория GitHub](docs/user/github-repository-preparation.md). `bp_check.py` проверяет подготовленное локальное состояние без сети и без автоматического исправления.

## Требования среды

1. Python `3.8+`; локальные инструменты используют только стандартную библиотеку и не требуют сторонних Python-пакетов.
2. Git `2.28+` нужен для режимов `sot_git` и `sot_github`, а также для полного запуска regression tests; в `sot_files` Git не читается и не вызывается.
3. Сетевой доступ и GitHub authentication относятся только к внешнему preflight `sot_github`; `bp_check.py` не использует GitHub CLI или сеть.

## Лицензия

BytePress распространяется по [MIT License](LICENSE). Лицензия downstream-продукта остаётся решением его владельца. При переносе BytePress лицензионное уведомление для компонентов BytePress сохраняется.

## Режимы источника истины

Поддерживаются ровно три режима:

1. `sot_files` — файловая работа без Git.
2. `sot_git` — локальный Git repository без remote.
3. `sot_github` — локальная рабочая копия заранее подготовленного GitHub repository.

Точный контракт и переходы описаны в [sops/sot.md](sops/sot.md). Режим не является разрешением на реализацию, продуктовую приёмку, выпуск или GitHub write.
