# BytePress Harness

BytePress помогает владельцу управлять работой агентов над продуктом: задавать цель и границы, сохранять контекст и получать проверяемый результат. **Человек управляет, агенты исполняют.**

Работа ведётся в Workspace — рабочей среде проекта. Сам продукт находится в отдельном каталоге и поставляется без внутренних планов и журналов. Harness — документы, процедуры, формы и инструменты, которые поддерживают эту организацию работы.

## Начать

[Создайте первый Workspace для нового продукта](docs/user/first-start.md). Нужны Python `3.12+`, распакованный BytePress и цель проекта. Установка сторонних Python-пакетов не требуется.

Если продукт уже существует, используйте [подключение существующего продукта](docs/user/existing-product.md). После создания среды переходите к [первой задаче](docs/user/after-project-start.md).
