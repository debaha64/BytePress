# Документация BytePress

Выберите ответ, который нужен сейчас. Для первого результата достаточно короткого пользовательского пути; внутреннее устройство можно изучить позже.

## Начать работу

[Первый Workspace](user/first-start.md) ведёт по одному сценарию нового продукта. [Пользовательские задачи](user/README.md) также объясняют подключение существующего продукта, следующий шаг после Project Start и обновление рабочей среды.

## Понять продукт

[О продукте](product/README.md): зачем нужен BytePress, какие потребности он закрывает и что поддерживает сейчас. [Архитектура](architecture/README.md) объясняет отношения Workspace, Product Unit и Project Profile.

## Найти точный ответ

[Технические темы](technical/README.md) описывают контракты создания среды, проверок, форматов и жизненного цикла. [Словарь](terminology/README.md) помогает различать термины.

Процедуры для исполнителей находятся в [SOP](../sops/README.md), формы — в [каталоге форм](../templates/README.md). Для понимания продукта читать их заранее не требуется.
