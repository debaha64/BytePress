# Задачи пользователя (JTBD)

Статус: draft.

## Назначение

Задачи пользователя, ради которых существует продукт.

## Основные задачи

1. Когда владелец начинает новый продукт, пользователь хочет быстро зафиксировать цель, аудиторию и границы, чтобы открыть работу без чужой истории и лишнего шума.
2. Когда смысл продукта ещё не выбран, пользователь хочет сохранить вопросы, решения и риски, чтобы следующий шаг был проверяемым.
3. Когда появляется первый результат, пользователь хочет видеть критерии готовности и текущие ограничения, чтобы оценить пользу продукта.

## Контекст

1. Продукт стартует локально как Product Unit.
2. Первая версия может оставаться в discovery-проходе фазы `04 Исследование` до отдельного решения владельца.
3. Кодовый и тестовый слои могут быть пустыми, пока продуктовая граница не утверждена.

## Критерии полезности

1. Пользователь понимает, какой ближайший результат готовится.
2. Пользователь видит, какие вопросы ещё открыты.
3. Пользователь может отличить продуктовый смысл от процедур обвязки.

## Не входит

1. Выбор стека без решения владельца.
2. Реализация продукта до утверждения границы.
3. Перенос процедур в продуктовые документы.
