# Форматы данных

## Project Profile и версия

Project Profile хранится как JSON по схеме v1 в корневом `<Slug>.profile`. Состав полей, ограничения имён и каноническая сериализация определены в [контракте Profile](../architecture/project-profile.md).

`VERSION` использует UTF-8 без BOM, одну строку версии и ровно одну завершающую LF. Связь значения с развёрнутым Profile определяет [SOP версий](../../sops/semver.md#развёрнутая-версия).

## Идентификаторы и связи

Workspace использует `WROAD-*`, `WBACK-*`, `WPLAN-*`. Эти записи находятся вне корня продукта и не входят в Project Profile. Идентификаторы `REQ-<GROUP>-<NNN>`, `INV-<NNN>` и `SCN-<NNN>` связывают требования, инварианты и сценарии внутри спецификации; они не образуют реестр рабочего процесса.

Публичный файл SHA-256 содержит контрольную сумму и только имя выпускного архива без пути. Применимость и имена задаёт [SOP версий](../../sops/semver.md#имена-снимков-и-поставок); внутренний манифест имеет собственный формат ниже.

## Полный исходный манифест TSV

Для проверки фактических изменений вызывающая сторона передаёт неизменяемый TSV-манифест всей постоянной файловой области. Заголовок имеет вид `manifest<TAB>1<TAB>complete<TAB>.`, строки — `type<TAB>mode<TAB>sha256-or--<TAB>relative-path`.

Строка задаёт тип объекта, POSIX-режим доступа, SHA-256 содержимого файла либо `-` и относительный путь. Из области исключаются только служебные проекции, `temp/` и временные следы исполнения. Неполный исходный манифест недействителен: по нему нельзя доказать отсутствие незаявленных изменений.

Короткий WPLAN использует `WORK_CONTRACT: v1`; прежний `SDLC_TRANSITION: v1` остаётся читаемым. Исходный TSV-манифест сохраняет формат v1. Временный registration-input — JSON с исходными байтами base64 и полями конкретной записи по task-intake; он не является новым постоянным реестром или источником полномочий.

## Фиксация версии программы

Сохранённый якорь: порядок изменения версии и исключения определяет [SOP версий](../../sops/semver.md#фиксация-версии-программы). Этот документ владеет сериализацией данных.
