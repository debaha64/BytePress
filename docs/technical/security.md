# Безопасность

## Смысловые границы

Безопасность Product Unit держится на явных границах: секреты не являются содержанием обвязки, удалённые действия не являются побочным эффектом технического PASS, а входные файлы владельца не становятся источником истины автоматически.

## GitHub и удалённые действия

GitHub, удалённые Git-действия, `push`, `PR`, `tag` и GitHub Release относятся к внешнему слою. Скрытое выполнение таких действий разрушает принцип: человек управляет, агенты исполняют.

`check_workspace.py` не читает данные доступа или настройки SSH, не вызывает сеть и не исправляет удалённое подключение. Внешняя предварительная проверка сверяет идентичность, URL, аутентификацию, метаданные репозитория и права без сохранения токена или закрытого ключа в Product Unit. `check_product.py` не интерпретирует SoT и получает унаследованное окружение только при явном запуске проверок средствами продукта.

## Входные файлы владельца

Входной файл владельца является источником сведений или свидетельством. Состояние Workspace он меняет только после решения владельца и переноса принятого смысла в принадлежащие Workspace `docs/`, `plans/` или `logs/`. Смысл, принадлежащий продукту, переносится отдельно внутрь границы поставки.
