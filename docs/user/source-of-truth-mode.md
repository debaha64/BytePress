# Режим источника истины

Режим источника истины определяет, где хранится каноническое состояние Workspace. Его машинное поле — `sot_mode` в корневом Project Profile.

| Значение | Где источник истины | Когда полезен |
|---|---|---|
| `sot_files` | файлы Workspace | начать без Git; проверка не читает `.git` |
| `sot_git` | локальный Git-репозиторий Workspace без удалённого подключения | вести локальную историю |
| `sot_github` | ветвь по умолчанию ожидаемого репозитория GitHub; локальный Git — рабочая копия | работать с внешним источником истины |

Project Start всегда создаёт `sot_files`. Для другого режима владелец открывает отдельный переход; одного редактирования значения недостаточно. [Технический контракт Git](../technical/git.md) объясняет проверяемые условия, [подготовка GitHub](github-repository-preparation.md) — необходимые действия пользователя.

Операционный режим — другое понятие: `product-work` означает обычную работу над продуктом, `system-editing` — разрешённое системное редактирование. Он не выбирает источник истины.

Режим источника истины сам по себе не разрешает реализацию, отправку изменений, PR, тег или выпуск. [Словарь](../terminology/glossary.md) различает режим, контрольную отметку и решение владельца; процедура перехода находится в [sot](../../sops/sot.md).
