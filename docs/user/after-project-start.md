# После Project Start

Workspace создан, но работа над продуктом ещё не началась. В нём есть профиль проекта, каталог продукта, документация Harness и места для планов и журналов.

## Что означает начальное состояние

В `plans/roadmap.md` активен только `WROAD-000001`: он хранит заданную вами общую цель. В `plans/backlog.md` находится контрольная отметка `WROAD-000001-OWNER-PLANNING`. Активного WPLAN нет: создание среды не выбирает первую задачу за владельца.

Текущее состояние смотрите в `plans/backlog.md`; когда появится исполняемый план — в `plans/active/`. Факты работы и решения будут записываться в `logs/`. Файл `<Slug>.profile` описывает состав и режим источника истины.

## Дать первую задачу

Откройте агента из корня созданного Workspace. Опишите, кому нужен продукт, какой результат хотите получить первым и какие ограничения существенны. Например:

> Хочу инструмент личных заметок. Первый результат — понять минимальный пользовательский сценарий и выбрать первую задачу. Данные должны оставаться локальными. Прочитай состояние Workspace, подготовь варианты и вопросы для моего решения.

Владелец выбирает задачу и разрешает её исполняемые границы. После этого агент открывает связанный WPLAN по процедуре Workspace. Технический PASS и команда «Продолжай» сами по себе не заменяют нового решения о смене границ.

[Модель задач](../technical/task-flow.md) объясняет WROAD/WBACK/WPLAN, а [режим источника истины](source-of-truth-mode.md) — где хранится текущее состояние.
