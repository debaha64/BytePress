# Agent Skills Product Unit

## Назначение

`skills/` поддерживает открытый стандарт Agent Skills без собственного формата BytePress. Канонический переносимый путь навыка: `skills/<name>/SKILL.md`.

## Граница

1. Основа Product Unit не требует встроенных навыков и поставляет `0` каталогов собственных Agent Skills.
2. Стандартный сторонний Agent Skill добавляется без изменений как каталог `<name>/` с обязательным `SKILL.md` и принадлежащими ему ресурсами.
3. Навык не расширяет полномочия PLAN, SYSTEM или SOP и не разрешает свои сценарии, зависимости или внешние действия автоматически.
4. Собственный формат, установщик, реестр, средство разрешения зависимостей и проверка навыков не создаются.
5. `SKILL.md` является стандартной формой навыка; отдельный глобальный `templates/skill.md` не нужен.

## Необязательное обнаружение Codex

Канонический источник остаётся в `skills/<name>/`. Если конкретной рабочей среде нужно обнаружение навыка в Codex, она может вне основы Product Unit создать относительную ссылку:

```text
.agents/skills/<name> -> ../../skills/<name>
```

Это необязательная клиентская проекция к тому же источнику, а не второй канонический каталог. Product Unit не поставляет `.agents/skills` и не меняет сторонний `SKILL.md` ради обнаружения.
