# Agent Skills

## Назначение

В пользовательском Workspace `skills/<name>/` — каноническая проектная копия внешнего Agent Skill с неизменным `SKILL.md`, ресурсами, лицензией и происхождением. Поставка BytePress содержит 0 Agent Skills: установка выполняется отдельно по запросу пользователя после Project Start.

## Граница

1. Навык не расширяет WPLAN, не создаёт решение владельца и не меняет SOP. Его команды и зависимости не исполняются автоматически.
2. Исходные файлы и ресурсы сохраняются без изменений; источник, точный commit, контрольные суммы и путь лицензии фиксируются здесь при установке.
3. Изменение или обновление внешнего навыка требует отдельного разрешённого прохода. Занятые пути сравниваются до записи; расхождение не перезаписывается молча.
4. Workspace Update сохраняет внешние и частные навыки, их ресурсы, лицензии, происхождение и клиентские проекции. У BytePress нет installer, registry, dependency resolver или собственного формата навыков.

## Обнаружение Codex

`skills/` само по себе является переносимой проектной копией. Для штатного обнаружения Codex рекомендуются обычные идентичные копии всех файлов и каталогов:

```text
skills/<name>/SKILL.md
skills/<name>/references/...
.agents/skills/<name>/SKILL.md
.agents/skills/<name>/references/...
```

`.agents/skills/` — техническая проекция, без собственных полномочий. Обычные файлы работают на Windows без Developer Mode, символических ссылок и специальных прав. После установки откройте Workspace новым чатом: применяются карта AGENTS и обнаруженные навыки. Обнаружение ещё не доказывает загрузку полного SKILL.md или корректное применение навыка.

Workspace checker проверяет полный состав каталогов и SHA-256 файлов каждой подключённой проекции против `skills/<name>/`. Несовпадение, пропущенный или лишний ресурс дают понятный FAIL с путём. Наличие только `skills/` допустимо, но не заявляется нативной проекцией. Прежняя относительная ссылка `.agents/skills/<name> -> ../../skills/<name>` совместима на POSIX; ссылки внутри ресурсов и чужие цели не принимаются.

Официальный путь Codex: [Build skills](https://learn.chatgpt.com/docs/build-skills), сверено 28.10.2026. [Жизненный цикл](../docs/technical/artifact-lifecycle.md) сохраняет границу служебной проекции.

## Отдельная установка рекомендуемого SkillPack

После Project Start откройте созданный Workspace и передайте агенту этот запрос. Он разрешает только установку, без реализации продукта:

```text
Прочитай AGENTS, Profile, SYSTEM и текущий маршрут. Выполни отдельный ограниченный WPLAN установки simple-first, decision-interview и translate-to-technical-russian из https://github.com/debaha64/SkillPack, версия 0.0.2, commit 1a71e214841ba721842cf29880d271d8c6e0ed91. При активном несовместимом WPLAN остановись и сообщи границу.
Сохрани точные исходные файлы в skills/<name>/ и все их ресурсы. Создай обычные идентичные копии в .agents/skills/<name>/, без symlink. Сохрани LICENSE этого commit как skills/SkillPack-LICENSE; SHA-256 лицензии 1ca6e0aec113805ffce1b3effc659aff7a855c308c53cc58d33cc530ced66624.
Проверь SHA-256:
decision-interview/SKILL.md 5c3d868df7b6a7dd6e80041682fc1ca5ad80471c0de826f8167afb2045a1a592
simple-first/SKILL.md 5df34d12f48f8eb99a5c40754b29f63129b85db024143bd9d17381858a1c35e7
translate-to-technical-russian/SKILL.md 0ff6c8ad9a07d0e602869249b0e7766b9085b1879820a67da170ec1e53a06c2f
translate-to-technical-russian/references/terminology.md 1afd26ff100a9a62b36f447ac0b3d92a503a6e3b975a7f17d8174f8d74a16eed
Проверь полный состав и хэши обеих копий. Сохрани частные навыки. Занятые пути сначала сравни, расхождения без отдельного решения не перезаписывай. Добавь только навигацию к трём навыкам в AGENTS.md и skills/README.md; здесь же зафиксируй источник, commit, суммы и путь лицензии. Остальные постоянные записи — только обязательный план и его свидетельства по действующим процедурам.

Не меняй Product или SOP и не начинай реализацию продукта. Сообщи результат и предложи открыть Workspace новым чатом.
```
