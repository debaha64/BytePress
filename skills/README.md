# Agent Skills

## Назначение

В пользовательском Workspace `skills/<name>/` — каноническая проектная копия внешнего Agent Skill. Она сохраняет:

- неизменный `SKILL.md`;
- все ресурсы;
- лицензию;
- происхождение.

Поставка BytePress содержит 0 Agent Skills: установка выполняется отдельно по запросу пользователя после Project Start.

## Граница

1. Навык не расширяет WPLAN, не создаёт решение владельца и не меняет SOP. Его команды и зависимости не исполняются автоматически.
2. Исходные файлы и ресурсы сохраняются без изменений. При установке здесь фиксируются:
   - источник;
   - точный commit;
   - контрольные суммы;
   - путь лицензии.
3. Изменение или обновление внешнего навыка требует отдельного разрешённого прохода. Занятые пути сравниваются до записи; расхождение не перезаписывается молча.
4. Workspace Update сохраняет:
   - внешние и частные навыки;
   - их ресурсы;
   - лицензии;
   - происхождение;
   - клиентские проекции.

BytePress не предоставляет:

- установщик;
- реестр;
- средство разрешения зависимостей;
- собственный формат навыков.

## Обнаружение Codex

`skills/` само по себе является переносимой проектной копией. Для штатного обнаружения Codex рекомендуются обычные идентичные копии всех файлов и каталогов:

```text
skills/<name>/SKILL.md
skills/<name>/references/...
.agents/skills/<name>/SKILL.md
.agents/skills/<name>/references/...
```

`.agents/skills/` — техническая проекция, без собственных полномочий. Обычные файлы работают на Windows без Developer Mode, символических ссылок и специальных прав. После установки откройте Workspace новым чатом: применяются карта AGENTS и обнаруженные навыки. Обнаружение ещё не доказывает загрузку полного SKILL.md или корректное применение навыка.

Workspace checker проверяет полный состав каталогов и SHA-256 файлов каждой подключённой проекции против `skills/<name>/`. Расхождение состава или байтов даёт понятный FAIL с путём. Наличие только `skills/` допустимо, но не заявляется нативной проекцией. Прежняя относительная ссылка `.agents/skills/<name> -> ../../skills/<name>` совместима на POSIX; ссылки внутри ресурсов и чужие цели не принимаются.

Официальный путь Codex: [Build skills](https://learn.chatgpt.com/docs/build-skills), сверено 28.10.2026. [Жизненный цикл](../docs/technical/artifact-lifecycle.md) сохраняет границу служебной проекции.

### Требования этой установки

- Установить только три указанных навыка с полным составом исходных файлов и ресурсов; сведения выше определяют точный источник.
- Сохранить проектные копии и обычные идентичные проекции Codex без symlink по разделу [«Обнаружение Codex»](#обнаружение-codex).
- Сохранить частные навыки и занятые пути по разделу [«Граница»](#граница).
- В `AGENTS.md` и этом `skills/README.md` добавить только навигацию к установленным навыкам. Здесь же зафиксировать фактическую установку по разделу [«Граница»](#граница). Данные рекомендации выше не являются свидетельством установки.
- Остальные постоянные записи ограничить обязательным планом и его свидетельствами по процедурам Workspace. Product и SOP не менять; реализацию продукта не начинать.

Общие процедуры принадлежат Harness:

- [приём задачи и совместимость с текущим маршрутом](../sops/task-intake.md);
- [план установки и управление работой](../sops/project-management.md);
- [обе штатные проверки Workspace/Product и фактическая дельта](../sops/verify-work.md);
- [завершение установочного прохода и отчёт](../sops/clean-exit.md).

После сообщения результата откройте Workspace новым чатом.
