# Запись качества

Целевой артефакт: `logs/quality.md`.
Шаблон или формат: `templates/quality-record.md`.
Способ записи: дозапись.

## Минимальное содержание

Запись качества содержит:

1. дату;
2. связь `WROAD/WBACK/WPLAN`;
3. команду или ручную проверку;
4. краткий итог;
5. очистку;
6. непроверенные области;
7. препятствие или остаточный риск;
8. следующий шаг.

Полный вывод команды не обязателен, если запись содержит проверяемый итог, точную ошибку или препятствие.

Канонический источник исполнения `SOURCE_REF` использует точный конечный диапазон `codexlog:.codex/<actual-log-file>#lines=<start>-<end>`. Локальная схема `QUALITY-*` задаёт ожидаемый класс результата и не требует внешнего индекса. Ссылка на диапазон только с промежуточной ошибкой не является итогом проверки.

Для очистки границы docs/SOP запись качества содержит классификацию оставшихся совпадений поиска: смысл, ссылка на SOP, остаточная протечка или будущий проход.

Для проверки DoD запись качества содержит:

1. связь с `WROAD -> WBACK -> WPLAN`;
2. выполненные проверки;
3. непроверенные области;
4. риски;
5. явную границу: DoD не является продуктовой приёмкой.

Для прохода изменения формата шаблона запись качества содержит:

1. выполненные команды;
2. свидетельство проверки связанных артефактов;
3. список непроверенных областей;
4. подтверждение, что выпуск, тег, архив и GitHub-действия не выполнялись;
5. подтверждение, что защищённые поверхности кода, инструментов и тестов не менялись, если это было ограничением WPLAN.

Для прохода изменения формата вывода запись качества дополнительно содержит:

1. ручную проверку длинных перечислений в изменённых файлах;
2. результат синхронизации README и индексов;
3. препятствие или остаточный риск по формату вывода.

Свидетельства соразмерны классу: `S0` — контрольное чтение; `S1` — целевые проверки; `S2` — машинные свидетельства, инженерная прослеживаемость, манифест, проверка согласованности и краткие свидетельства для владельца. Отдельно указывать результат Verification, статус Validation и точку решения владельца; технический PASS не повышает их автоматически.
