# Диагностика системы

## Назначение

Диагностика показывает состояние Workspace без автоматического исправления.

## SoT/Git

Диагностика один раз разбирает `sot_mode` из единственного корневого Project Profile и условный `SOT_GITHUB_REPOSITORY` только для `sot_github`.

В `sot_files`:

1. путь `.git` не читается, не классифицируется и не проверяется;
2. Git CLI не вызывается;
3. состояние контролируется файловыми средствами вне `.git`.

В `sot_git` проверяются:

1. валидность корня локального репозитория;
2. существование базового коммита;
3. отсутствие удалённого репозитория;
4. рабочая ветка и чистота дерева по правилам текущей проверки.

В `sot_github` дополнительно проверяются единственный `origin`, URL и идентичность репозитория, отслеживаемая ветвь, существующие удалённые ссылки, символическая `origin/HEAD` и допустимое расхождение. Диагностика не вызывает сеть, не выполняет `fetch` и не исправляет состояние.

Подтверждение запуска команды оболочки не заменяет решение владельца.
