# Управляемый проход агента

Этот путь сохранён как краткий вход для существующей поставки Project Start: `tools/new_project.py` копирует его по фиксированному перечню. Самостоятельной процедуры здесь нет; поведение Harness не расширяется.

Единственный владелец управляемого прохода — [управление проектом](project-management.md). Начальные действия выполняются по [старту сессии](start-session.md), приём запроса — по [приёму задачи](task-intake.md), а режим источника истины обрабатывается по [SoT](sot.md).

Прежние правила интервью и отдельного разрешения `local_git_route` находятся в [интервью](interview.md). Порядок SDD/TDD задают [модель задачи](../docs/technical/task-flow.md) и [процедура изменений](change-management.md). Проверка и завершение принадлежат [verify-work](verify-work.md) и [clean-exit](clean-exit.md).

Эти ссылки не создают полномочий: решение владельца и свидетельства нельзя синтезировать, а реализация, приёмка и выпуск сохраняют отдельные точки контроля.
