# Применение инженерных этапов

Каталог и назначение этапов принадлежат [SDLC](../docs/technical/sdlc.md), условия действий — [phase-gates](../docs/technical/phase-gates.md). Выбирать только необходимые для результата этапы: исследовать неизвестное, сформулировать ожидаемое поведение, спроектировать затронутые границы, получить применимое решение, проверить изменения. Обязательного перехода по всему графу в коротком WPLAN нет.

Роли обозначают ответственность; WPLAN задаёт исполняемую границу, продуктовые документы и решения сохраняют состояние продукта. Для проверяемого поведения сохраняются tests-first и уровни доказательности по task-flow. Результат этапа не разрешает следующее действие автоматически. Старые SDLC_TRANSITION читаются по разделу совместимости phase-gates; completed history не переписывается.
