# Список задач Workspace

| WBACK | WROAD | Статус | Результат и DoD | WPLAN / свидетельство |
|---|---|---|---|---|

WBACK хранит известную работу; несколько задач могут оставаться незавершёнными. Исполнение разрешает только активный WPLAN. Количество WPLAN и текущий шаг вычисляются из plans/active; ручная копия маршрута здесь не обязательна.

Новая pending запись по прямому входу добавляется в конец файла по [task-intake](../sops/task-intake.md#узкая-регистрация); старые таблицы сохраняются. Consumer: `sops/project-management.md`.
