# Завершённые WPLAN

| WPLAN | WROAD/WBACK | Результат | Verification | Точка решения владельца и закрытие |
|---|---|---|---|---|

Завершённый WPLAN неизменяем и сохраняет ID. Файл принадлежит `WS_<Slug>/plans/completed/` и создаётся как статическая заготовка без истории конкретного Workspace.

Крупные технические приложения без другого предметного владельца могут находиться в `WPLAN-<ID>/<существующее имя файла>`. Каталог создаётся только при необходимости и не является отдельным WPLAN, состоянием или планом. Markdown-файл плана и его ID сохраняются. Небольшой итог хранится непосредственно в WPLAN; журналы содержат события и ссылки.
